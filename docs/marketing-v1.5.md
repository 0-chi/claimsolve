# クレソル(ClaimSolve)マーケティング設計書 v1.5

v1.4 のレビュー指摘(A-1〜A-5 / B-1〜B-4 / C-1〜C-10 / D-1〜D-4)を反映した改訂版。
本書は要件定義書 v2.9 の追補であり、矛盾する場合は本書が優先される。
本書の「コピー」はすべて実際に画面へ出す文言である。要約・意訳をしない。

## v1.4からの変更点(レビュー反映)

- **A-1**: 企業LPのファーストビューは`?from=notice`(通知メール経由)のときのみ「貴社への報告が届いています」。デフォルトは「報告が届いたら、まず無料で読めます」
- **A-2**: 中核コピーを事実に忠実化。「企業名が公表されることもありません」→「企業名も、**原則として**公表されません」/「読み返すことはできません」→「読み返す**仕組みはありません**」
- **A-3**: `monetization_enabled` は**個人閲覧プラン(150円)のみ**を制御する(v2.9どおり)。**企業向け価格(1,980円)は常時表示**
- **A-4**: 通知の正直表示は**3状態**(登録済み/通知先あり未登録/**通知先不明**)。通知先不明では「通知します」と言わない。「返答なしも記録」の文言は通知到達案件に限定
- **A-5**: live投稿の正直表示・完了画面に「**運営の確認のうえ公開・通知します**」を明記(admin承認フローは維持)
- **B-1**: OGP例示のスコアとバッジを閾値に一致させる(6.0以上=普通)
- **B-2**: 企業FAQ「公開されるのは事実データのみ」→「**やり取り(スレッド)は非公開。公開されるのは投稿内容と事実データ**」
- **B-3**: 記事KPIは **past+silent+live の合算**
- **B-4**: 早期特典の対象を「**本文100字以上のレビュー**」に限定して表記
- **C-1**: 離脱受け皿のstaff切替は「**担当者の対応についてなら**」と主題を限定
- **C-2**: silentブロックの「文句を言いにくい会社が見えてくる」→「**窓口の届きにくさが数字で見えてくる**」(UR準拠)
- **C-3**: 投稿0件判定は**公開投稿(past/silent/live)のみでカウント(staffは数えない)**。0件企業はページ生成・インデックスなし。サイト内検索では法人マスタから「最初の1件を書きませんか」CTAカードで出す
- **C-4**: OGPは**企業ページ・記事・レビュー詳細のみ**。staff/silentの詳細にOGPを生成しない
- **C-5**: 企業LPのトライアル表記直下に「**クレジットカードの登録が必要です**」を明記
- **C-6**: GA4導入に伴い、プライバシーポリシーへ**外部送信規律**(改正電気通信事業法)の記載を追加
- **C-7**: 営業文言禁止は**全通知メール**に適用(v2.9 §6と整合)
- **C-8**: 企業LPのFAQに**削除・開示請求窓口(/request)**への導線を追加
- **C-9**: 架空シードの撤去を**マーケ公開の前提条件**として明記
- **C-10**: 初期記事5本の内訳を指定: **A×2(センター相談前・188の使い方)/B×2(引越し・美容)/C×1(サブスク解約手順)**
- **D-1**: ヒーロー直下にsilentの副CTAを併置
- **D-2**: 相談件数の出典は「国民生活センター(PIO-NET・年度)」形式で年度を必ず付す
- **D-4**: 通知メールのリンクにのみ計測パラメータを付与(本文は事務連絡テンプレのまま)

## §1. 要件定義書 v2.9 への変更指示

### 変更1 — liveレーンを解禁する
live_enabled は**初期値ON**(緊急停止用のOFF切替は維持)。liveが約束するのは「解決」ではなく「**記録+通知(返答は保証しない)**」。返答の有無そのものが記録・スコアになる。

### 変更2 — ポジショニング(厳守)
「消費生活センターの代わり」ではなく「**センターの手前**」。公的機関を名乗る・紛らわしい名称/意匠は全面禁止。センターの「あっせん」の優位は正直に認め、補完関係として提示する。

### 変更3 — FeatureFlag
`live_enabled` 初期値ON。`monetization_enabled` が制御するのは**個人閲覧プランのみ**。企業向けライトプランの価格・販売はローンチ時から常時有効。

### 変更4 — 通知の正直表示(3状態・必須)
企業選択時に次を出し分ける。「企業が対応します」等の期待表現は禁止。全状態に「**運営の確認のうえ公開・通知します**」を併記する。

1. **登録済み企業**:「この企業はクレソルに登録済みです。あなたの報告は運営の確認のうえ公開され、企業に届きます。返答があれば通知します」
2. **未登録・通知先あり**:「この企業はまだクレソルに登録していません。報告は運営の確認のうえ公開され、通知メールも送りますが、返答があるかは分かりません。通知が届いた場合、返答がなかったことも記録として残ります」
3. **通知先不明**:「この企業への通知手段がまだありません。報告は運営の確認のうえ公開されますが、企業に届いたかどうかは記録されません」

### 変更5 — 約束の範囲と公的窓口への案内
「解決します」「企業が対応します」と読める表現を全面禁止。約束は①記録が残る ②(通知先があれば)通知される ③返答の有無が記録される、の3点のみ。
live投稿の完了画面と投稿者専用ページに **消費者ホットライン188** と消費生活センターの案内を常設。順序は「**まず公的窓口へ相談を。その記録をここに**」。

### 変更6 — SEO
- **公開投稿(past/silent/live)が0件の企業ページは生成もインデックスもしない**(staffは数えない)
- 企業ページ・記事・レビュー詳細に next/og の動的OGP(**staff/silentの詳細には生成しない**)
- GA4 + Google Search Console を導入(**外部送信規律への対応をプライバシーポリシーに記載**)

### 変更7 — 実装順序
live=ONで実装・テスト(承認→正直表示→通知→マジックリンク→非公開スレッド→7/14日解禁→評価→異議→188常設)。最終手順の前に「LP(消費者`/`・企業`/business`)+記事5本+空状態+OGP+GA4/GSC」を挿入。

### 変更8 — 受け入れチェックリスト追加
```

- [ ] 企業選択時の正直表示が3状態で出し分けられ、通知先不明で「通知します」と表示されない
- [ ] 全画面・全メールに「解決します」「企業が対応します」と読める表現がない
- [ ] live完了画面と投稿者ページに188案内(「まず公的窓口へ」の順序)
- [ ] 消費者LPの対比表1行目が「あっせん=センター○/クレソル✕」
```

## §3. 消費者LP(`/` 上段・gate_enabled連動)

### 3.1 ヒーロー
- 見出し: **その"泣き寝入り"、供養しませんか。**
- サブ: 誰にも言えないまま終わった、あの一件。次に同じ目にあう誰かへの「申し送り」に変える場所をつくりました。
- 主CTA「まずは1件、書く」+ **直下に副CTA「言わずに終わったことを記録する」**

### 3.2 事実
- 消費生活相談は年間およそ**91万件**(出典: 国民生活センター PIO-NET・2023年度 ※公開前に最新の公表値と年度を確認)
- 添え書き:「これは"相談まで行った人"の数。言えずに終わった人は、ここに入っていません。」

### 3.3 中核コピー(一字一句このまま)

> **あなたの相談は、国のデータベースに記録されます。ただし、それを読み返す仕組みはありません。**
>
> 消費生活センターに寄せられる相談は、年間およそ91万件。すべてPIO-NETという行政のデータベースに記録されています。でも、次に同じ会社と取引しようとしている人が、その中身を読むことはできません。企業名も、原則として公表されません。
>
> クレソルは、そこを引き受けます。あなたが書いた5分が、次に同じ目にあうはずだった誰かを守ります。

- 被害回復額など具体的な金額の記載は禁止/「記録が残らない」と書かない

### 3.4 対比表(1行目=あっせん。順序変更禁止)
(v1.4と同一)

### 3.5 「言わなかった人へ」(対比表の直後)

> **言わなかった人にも、書く場所を。**
>
> 文句を言うほどでもなかった。でも、もう二度と使いたくない。——いちばん多いのに、いちばん残っていないのが、この記録です。
>
> クレソルは「**なぜ、言わなかったのか**」を聞きます。企業を告発するためではありません。「連絡先が分からなかった」「繋がらなかった」という理由が集まると、**窓口の届きにくさが数字で見えてくる**からです。
>
> 選ぶだけ、50字から。**3日間、他の人の記録が読み放題になります。**

### 3.6 書き方は4つ(v2.9の数値に厳密一致)
(v1.4と同一の表。live行は「※運営の確認のうえ公開・通知」と注記)

### 3.7 早期特典(gate OFFのみ)

> **いまなら、誰でも全部読めます。**
> 公開された投稿が200件を超えた時点で、全文閲覧は会員限定に切り替わります。いま**本文100字以上のレビュー**を書いておけば、切り替わった日から**1ヶ月ぶん**の閲覧権があなたに残ります。

### 3.8 安全性 / 3.9 CTA+188
(v1.4と同一。188の順序は「まず公的窓口へ。その記録を、ここに。」)

## §6. 空状態
- 公開投稿0件の企業ページは生成もインデックスもしない(**staffは数えない**)
- サイト内検索: Companyに無い企業は**法人マスタからCTAカード**(「◯◯社の報告はまだありません。最初の1件を書きませんか」+silent併置)で出す
- ランキング・総件数は充足まで非表示/AR・SR・URは5件未満「集計中」

## §7. OGP・計測
- 企業ページOGP: 「スコア5.8 / 改善余地 / レビュー42件」形式(**バッジはv2.9閾値と一致させる**)
- 記事・**レビュー詳細**にOGP。**staff/silentの詳細には生成しない**
- GA4 + Search Console(env: `NEXT_PUBLIC_GA_ID` / `NEXT_PUBLIC_GSC_VERIFICATION`。未設定なら読み込まない)
- **外部送信規律**: GA4使用時の情報送信についてプライバシーポリシーに記載
- 通知メールは事務連絡テンプレのまま、**リンクURLにのみ**計測パラメータ(`?from=notice`等)
- ページ別KPI: 記事=投稿開始率(**past+silent+live合算**)/企業ページ=投稿開始+ウォッチ/トップ=投稿完了/フォーム離脱時のsilent・staff切替率/staff着信→ライトプラン転換率/参考になった→対策バッジ転換率
